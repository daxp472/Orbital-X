# Orbital X v2.3.8 Release Notes

**Release Tag:** `v2.3.8`  
**Date:** November 12, 2026  
**Focus:** Hybrid Portable Architecture (USB Carrying IDE Environment + Host Compute Power), Software Updates Suite & Native Markdown Release Highlights, Apple HIG Recent Chats Redesign, Developer Diagnostics Suite & Dynamic Version Synchronizer.

---

### 1. Hybrid Portable Application Architecture
- **Environment Mobility on USB:** Orbital X carries the user's complete personalized IDE environment—settings, appearance, themes, installed extensions, custom skills, agent prompt instructions, and portable chat sessions—directly on the USB drive under `Data/.orbital/`.
- **Host Machine Compute Synergy:** Seamlessly taps into each host machine's processing power: local Ollama runtime and models (`http://127.0.0.1:11434`), discrete GPU acceleration, system RAM, compilers (`cargo`, `tsc`, `python`), and machine-specific system tools.
- **Project Knowledge Independence:** Project workspace memory resides inside each project's own `.orbital/` folder, ensuring projects remain completely independent of the USB drive.
- **Bi-Directional 1-Click Synchronization:** Built-in dual-safe synchronization commands (`sync_project_memory_to_portable` and `sync_project_memory_from_portable`) allow users to safely back up workspace memory to USB and restore it onto any host with a single click.
- **Crash-Safe Atomic Persistence:** Implemented atomic temp file writes (`.tmp` write -> fsync -> rename) and automatic backup recovery (`.bak`) in Rust to protect against USB detachment during disk writes.
- **Multi-Instance Lock Guard:** File-based lock (`Data/.orbital/portable.lock`) tracking PID, hostname, and timestamp prevents corrupted writes if multiple portable instances are launched.

---

### 2. Software Updates Suite & Native Markdown Viewer
- **Apple HIG & Liquid Glass Design:** Fully redesigned updates interface adhering to Apple Human Interface Guidelines with zero emoji visual noise, high-contrast badges, and clean typographic rhythm.
- **Dynamic System Metrics Grid:** Live indicators for Installed Version, Latest Stable, Release Channel, and Runtime Mode (USB Portable vs Host Machine).
- **Native Markdown Highlights Viewer:** Internal development notes (`iteration.md`, `implementation.md`) are kept strictly in engineering directories. End users receive beautifully formatted release highlights directly rendered with safe native Markdown.
- **Dynamic Binary Version Verification:** Removed static version literals in frontend code. Orbital X dynamically queries the native Rust backend (`get_app_version()`) and GitHub release APIs to eliminate false "Update Available" prompts.

---

### 3. Recent Chats Manager Redesign
- **Vector Iconography:** Replaced all emojis with crisp SVG vector icons for conversation management (Pin, Archive, Export, Delete, and Search).
- **Search & Quick-Filter Tabs:** Added instantaneous real-time title search and category tabs (`Active`, `Pinned`, `Archived`) with item counts.
- **Session Lifecycle Management:** Smooth pin/unpin toggling, archive/unarchive transitions, and confirm-guarded deletion with immediate visual feedback.

---

### 4. Fully Audited Developer & Diagnostic Suite
- **Hybrid Portable Environment Inspector:** Live card displaying portable USB mount paths, crash lock guard status, and synced workspace backup counters.
- **Verified Native IPC Benchmarking:** Core IPC Ping test measuring live round-trip latency to the Tauri v2 backend with sub-millisecond precision.
- **Kernel Policy Simulator:** Real-time sandboxing simulation testing filesystem and execution boundaries across Dev, Agent Pro, and User modes.
- **Dynamic Diagnostics:** Clipboard diagnostics exporter dynamically pulls native runtime metadata, OS user-agent, active provider status, and memory states.
