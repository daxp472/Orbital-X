## 1. Executive Summary & Objective

Iteration 005 brings transformative AI speed, native telemetry, and resilience to Orbital X while strictly locking version `v2.3.1`:

1. **Multi-Model Speculative Streaming (~4,000 LOC capability):**
   - **Dual-Model Concurrent Engine:** Runs two local Ollama models concurrently (e.g. an ultra-fast draft 0.5B/1.5B/3B model and a core 7B/14B reasoning model).
   - **Monaco Editor Integration:** Speculatively streams sub-10ms ghost-text completions into Monaco while a background verifier thread validates syntax and logic.
   - **Settings & Auto-Detection Suite:** Includes master On/Off toggle, 1-click Auto-Set to automatically identify the optimal draft model from installed Ollama models, manual model overrides, and dynamic hardware use-case telemetry cards.

2. **Zero-Allocation Token Telemetry & VRAM Tracker:**
   - **Native Hardware Polling:** Built with Rust crates (`sysinfo`), pulling real-time host metrics, CPU load, process RSS memory, and GPU VRAM allocations without bloating Node modules.
   - **Live HUD Dashboard:** Embedded statusbar HUD displaying live Tokens/Second, context window percentage, RAM usage, and GPU load.

3. **The "Time-Travel" Agent Journal:**
   - **Virtual File System Snapshots:** Automatically creates atomic snapshot patches of the workspace before and after every agent turn.
   - **Visual Timeline & Instant Rollback:** Visual scrubber timeline modal enabling 1-click file diff previews and instant rollbacks of entire multi-file agent modifications without relying on undo history.

4. **Strict Context Window Allocation (Zero Hardware Clamping):**
   - **User Rule Enforced:** Context length is strictly dictated by the number set in Model Settings (e.g., 8,192 or 16,384 tokens) without any downscaling, clamping, or modification based on device RAM, VRAM, or hardware profiles. A machine with 6 GB VRAM gets exactly the specified context window, just as a machine with 16 GB VRAM does.
   - **Expanded Conversation Budget:** Retains high context availability (`numCtx - 512`) ensuring maximum context utilization.

5. **In-Chat Auto Mode & Speculative Toggle:**
   - **Direct Composer Access:** Added `#composer-speculative-toggle` directly next to the model selector pill in the chat composer (`.composer-bottom-bar`). Users can switch between standard manual mode and Auto Speculative Dual-Model Mode with a single click.
   - **Model Picker Integration:** Added an Auto / Speculative dual-model management card inside the model picker dropdown with automatic model pairing.
   - **Smart Auto-Routing:** When Auto Mode is active, agent turns intelligently route simple inquiries to fast draft models and heavy coding/architecture tasks to deep verifier models.

6. **Agent Self-Identity & Architecture Knowledge:**
   - **Core Identity in System Prompt:** Embedded rich creator and architectural facts into the base system prompt: created and engineered by Dax Patel and the Orbital X Team; built with Rust, Tauri v2, Monaco Editor, offline Ollama inference, and tri-mode security.
   - **Welcoming Persona:** Configured to be warm, friendly, clear, and engaging when curious non-programmers or first-time users ask who it is, how it works, or what they can do with it.
