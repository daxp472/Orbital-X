## 2. Root Cause Analysis (RCA)

### Issue A: Open Workspace Picker Failing / "Going Back"
1. **COM Apartment Conflict on Windows (`RPC_E_CHANGED_MODE`):**
   - *Cause:* Windows Shell Dialogs (`IFileDialog`) require Single-Threaded Apartment (STA). When spawned on Tokio's shared async runtime worker pool, the thread often inherited Multi-Threaded Apartment (MTA) or conflicting COM initializations, causing `rfd::FileDialog::pick_folder()` to return `None` immediately without showing a window.
   - *Fix:* Dedicated OS thread creation (`std::thread::Builder::new().name("orbital-folder-picker".into()).spawn(...)`) ensures a fresh, uncontaminated COM apartment context on every picker request.
2. **Missing Parent Window Handle (`set_parent`):**
   - *Cause:* Without attaching the HWND of the main window, the native Windows folder picker was created as an unowned modal. In Windows 10/11, unowned dialogs frequently open behind the full-screen IDE window, giving the impression that nothing opened.
   - *Fix:* Attached `app_handle.get_webview_window("main")` via `dialog.set_parent(&win)`.
3. **Data Type Mismatch in Client IPC Response:**
   - *Cause:* Depending on the platform plugin layer, `@tauri-apps/plugin-dialog` or Tauri IPC can return directory selections as an Array (e.g. `['D:\\project']`) or an Object (`{ path: '...' }`). In `src/js/app.js`, `enterWorkspace` previously executed `if (typeof rootPath !== 'string') return;`, causing an immediate silent abort when an array was returned.
   - *Fix:* Introduced `extractPath()` in `src/js/services/tauri.js` and flexible array/object unwrapping in `enterWorkspace()`.
4. **Missing Function Reference Error (`rememberWorkspaceTrust`):**
   - *Cause:* `enterWorkspace` called `rememberWorkspaceTrust(meta.root_path, true);`, but the function was missing from `src/js/app.js`. This threw an uncaught `ReferenceError`, halting execution before `await loadWorkspace()` could be reached.
   - *Fix:* Implemented and exported `rememberWorkspaceTrust(rootPath, trusted = true)` with `localStorage` persistence.
5. **Intrusive Trust Gate Blocking:**
   - *Cause:* `promptWorkspaceTrust` was triggering a synchronous `window.confirm()` dialog whenever a folder was opened, causing focus loss and aborting the workspace load if dismissed.
   - *Fix:* Automatically trust directories explicitly selected by the user via the native OS folder picker.

### Issue B: Agent Operating Mode Changing
1. **Unbound Status Bar Mode Pill:**
   - *Cause:* Users clicking "Dev Mode" on the bottom status bar had no effect because `#status-mode` had no click listener.
   - *Fix:* Bound `#status-mode` to toggle the mode switcher popover and updated the live indicator dot color (`agent_pro`: purple, `dev`: cyan, `user`: green).

## 4. Technical Details of Implementation

### Backend: Dedicated OS Thread Folder Picker (`src-tauri/src/lib.rs`)
```rust
#[tauri::command]
async fn open_folder_dialog(app: tauri::AppHandle) -> Result<Option<String>, String> {
    let (tx, rx) = tokio::sync::oneshot::channel();
    let app_handle = app.clone();

    // Spawn a dedicated OS thread with its own COM apartment
    std::thread::Builder::new()
        .name("orbital-folder-picker".into())
        .spawn(move || {
            let mut dialog = rfd::FileDialog::new().set_title("Select Workspace Folder");
            if let Some(win) = app_handle.get_webview_window("main") {
                dialog = dialog.set_parent(&win);
            }

            if let Some(path_buf) = dialog.pick_folder() {
                let clean = workspace::strip_verbatim_prefix(&path_buf);
                let path_str = clean.to_string_lossy().to_string();
                if clean.is_dir() {
                    let _ = tx.send(Some(path_str));
                    return;
                }
            }

            // Fallback to tauri_plugin_dialog with WebviewWindow
            use tauri_plugin_dialog::DialogExt;
            if let Some(win) = app_handle.get_webview_window("main") {
                if let Some(file_path) = win.dialog().file().set_title("Select Workspace Folder").blocking_pick_folder() {
                    if let Ok(path_buf) = file_path.into_path() {
                        let clean = workspace::strip_verbatim_prefix(&path_buf);
                        let path_str = clean.to_string_lossy().to_string();
                        if clean.is_dir() {
                            let _ = tx.send(Some(path_str));
                            return;
                        }
                    }
                }
            }

            let _ = tx.send(None);
        })
        .map_err(|e| format!("Failed to spawn folder picker thread: {}", e))?;

    match rx.await {
        Ok(res) => Ok(res),
        Err(_) => Ok(None),
    }
}
```

### Frontend: Robust Path Extraction (`src/js/services/tauri.js`)
```javascript
export async function pickFolder() {
  function extractPath(res) {
    if (!res) return null;
    if (typeof res === 'string' && res.trim()) return res.trim();
    if (Array.isArray(res) && res.length > 0) {
      const first = res[0];
      return typeof first === 'string' ? first.trim() : (first?.path || first?.filePath || null);
    }
    if (typeof res === 'object' && res !== null) {
      return res.path || res.filePath || res.fsPath || null;
    }
    return null;
  }

  // 1. Primary: Rust IPC open_folder_dialog
  try {
    const res = await invoke('open_folder_dialog');
    const path = extractPath(res);
    if (path) return path;
    if (res === null) return null; // Cancelled
  } catch (e) {
    console.warn("open_folder_dialog IPC failed, trying plugin dialog fallback:", e);
  }

  // 2. Client-side plugin fallback
  try {
    const dialog = await import('@tauri-apps/plugin-dialog');
    if (dialog && typeof dialog.open === 'function') {
      const res = await dialog.open({ directory: true, multiple: false, title: 'Select Workspace Folder' });
      const path = extractPath(res);
      if (path) return path;
      if (res === null) return null;
    }
  } catch (e) {
    console.warn("@tauri-apps/plugin-dialog fallback failed:", e);
  }

  // 3. Fallback for browser testing
  if (!window.__TAURI__ && !window.__TAURI_INTERNALS__) {
    return prompt("Enter workspace directory path:", "D:/1work/YT/Orbital X");
  }
  return null;
}
```

## 5. Production Rollback & Troubleshooting Guide

If an issue occurs in production with workspace loading or mode switching, use this section for instant recovery:

### Issue 1: Folder picker does not show up
- **Symptom:** User clicks "Open Workspace", cursor changes, but no dialog appears.
- **Immediate Recovery Action:**
  1. Open DevTools in Orbital X (`Ctrl+Shift+I` or right-click -> Inspect).
  2. Run in Console:
     ```javascript
     import('./services/tauri.js').then(m => m.invoke('open_folder_dialog').then(console.log));
     ```
  3. If `open_folder_dialog` returns an error, the client fallback can be manually invoked:
     ```javascript
     import('@tauri-apps/plugin-dialog').then(d => d.open({ directory: true }).then(p => import('./app.js').then(a => a.enterWorkspace(p))));
     ```
  4. Alternatively, open any folder directly via console:
     ```javascript
     import('./app.js').then(a => a.enterWorkspace("D:\\your\\folder\\path"));
     ```

### Issue 2: Folder selected but workspace doesn't load
- **Symptom:** User selects folder, dialog closes, but file tree remains empty.
- **Root Cause Check:**
  1. Check localStorage trust map:
     ```javascript
     localStorage.getItem('orbital_workspace_trust');
     ```
  2. If marked `false`, reset it:
     ```javascript
     localStorage.removeItem('orbital_workspace_trust');
     ```
  3. Re-enter the workspace:
     ```javascript
     import('./app.js').then(a => a.enterWorkspace(localStorage.getItem('orbital_last_workspace')));
     ```

### Issue 3: Agent Mode stuck or cannot switch
- **Symptom:** Clicking the mode pill does not change the active agent mode.
- **Immediate Recovery Action:**
  1. In Console, execute:
     ```javascript
     import('./components/agent.js').then(m => m.switchMode('agent_pro')); // or 'dev', 'user'
     ```
  2. Check localStorage:
     ```javascript
     localStorage.setItem('orbital_mode', 'dev');
     ```
