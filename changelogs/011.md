# Orbital X v2.3.7 Release Notes

**Release Tag:** `v2.3.7`  
**Date:** November 11, 2026  
**Focus:** Professional Notification Center Redesign, True Portable Mode, Inline Code Suggestions Engine, Minimal Status Bar Redesign & Explorer State-Preserving Reconciliation.

---

### 1. Professional Notification Center Redesign (VS Code / Cursor Quality)
- **Elimination of Emoji-Heavy UI:** Replaced all emoji glyphs with an SVG vector icon library across all notification categories and severities.
- **Unified Filtering & Category Navigation:** Clean, modern tabs (`All`, `Tasks`, `Milestones`, `Files`, `Errors`) with item count badges and streamlined layout.
- **Curated Density Customization:** Real-time persona filtering (`Curated (low noise)`, `Balanced`, `All Activity`) with persistent preference memory.
- **Actionable Cards & Navigation:**
  - One-click file navigation directly opens files in Monaco Editor tabs, scrolling and centering on the exact affected line numbers.
  - One-click task and milestone navigation immediately routes into the Agent session view.
  - Hover-activated individual dismiss button (`×`) and bulk action buttons (`Mark All as Read`, `Clear All`).
- **Single Scroll Container:** Completely decoupled layout so only the notification list scrolls (`overflow-y: auto`), eliminating nested or persistent scrollbars.

---

### 2. True Portable Application Runtime
- **Automatic Portable Detection:** Self-activates portable mode if sibling `Data/` folder, `PORTABLE` file, or `--portable` CLI argument is detected.
- **Total Workspace & AppData Isolation:** Re-routes WebView2 runtime data (`WEBVIEW2_USER_DATA_FOLDER`), local application configuration, and project workspaces to the portable root folder without touching host user directories.
- **Fail-Fast Safety:** Prevents silent write fallbacks to the host OS if the portable drive becomes read-only or detached.

---

### 3. Inline Code Suggestions Engine
- **Fill-In-The-Middle (FIM) Context Formatting:** Proper `<｜fim begin｜>`, `<｜fim hole｜>`, `<｜fim end｜>` tokenization for DeepSeek Coder, CodeLlama, and StarCoder local models.
- **Word-Prefix & Stale Request Deduplication:** Prevents duplicated word completions when typing ahead in Monaco.
- **Typing Cancellation & Debounce:** Automatically aborts outdated pending requests when typing resumes, keeping the editor lag-free.
- **Cost-Protected Cloud Suggestions:** Local Ollama suggestions enabled by default; cloud providers require explicit user opt-in to avoid unexpected API costs.

---

### 4. Bottom Status Bar & Explorer Reconciliation
- **Minimalist Status Bar:** Clean VS Code-inspired layout grouping branch info, language modes, encoding, and a unified `● Pillars: OK` health pill.
- **State-Preserving DOM Reconciliation:** Live Explorer preserves directory expansion state, active file selection, and scroll positions across agent mutations.

---

### 5. Multi-Platform Verified Distribution Assets
- **Windows:** `Orbital.X_2.3.7_x64-setup.exe` (NSIS Installer) & `orbital-x.exe` (Standalone Executable)
- **macOS:** `Orbital.X_2.3.7_aarch64.dmg` & `Orbital.X_aarch64.app.tar.gz`
- **Linux:** `Orbital.X_2.3.7_amd64.AppImage` & `Orbital.X_2.3.7_amd64.deb`
