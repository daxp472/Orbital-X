## 2. Root Cause Analysis (RCA)

### Issue A: Report Issue Button Never Opened the Web Page
- **Root Cause:** In `src/js/app.js`, `sb-report-issue` and `btn-help-report-issue` executed:
  ```javascript
  const response = await fetch('https://github.com/daxp472/Orbital-X', { method: 'HEAD' });
  await invoke('open_url', ...);
  ```
  GitHub strictly disallows cross-origin `HEAD` requests from WebView applications. The `fetch` threw a network `TypeError` on every attempt, routing execution directly into the `catch` block which rendered an offline dialog instead of launching the browser.
- **Resolution:** Removed the CORS network check and invoked `open_url` directly via Tauri IPC.

### Issue B: Stretched & Non-standard Developer Dropdown
- **Root Cause:** Developer menu in `developer-menu.js` used a custom wide box without fixed IDE boundaries, while `File`, `Edit`, `Terminal`, and `Help` had no unified dropdown system.
- **Resolution:** Implemented `src/js/components/menubar.js` with compact, standard IDE dimensions (240px-280px width, 28px row height, right-aligned shortcuts, grouped dividers) matching standard IDE specifications (Screenshot 2).

### Issue C: Silent Auto-Update Comparison Bug
- **Root Cause:** In `initUpdateCheck()`, version comparison logic evaluated `n > (latest.split('.').map(Number)[i] || 0)`, comparing `latest` against itself rather than `CURRENT_VERSION`.
- **Resolution:** Replaced with `isVersionNewer(remote, current)` in `updater.js` that compares semantic version parts sequentially.
