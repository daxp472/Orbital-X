# Orbital X v2.4.4 — Release Highlights

## What's New in Version 2.4.4

Orbital X v2.4.4 introduces the **Universal 3-in-1 Cross-Platform USB Portable Suite** (`Orbital-X-Portable.zip`), an integrated **VS Code-Grade Terminal Overhaul** with line-wise command decorations and real-time syntax highlighting, and permanent resolution of the chat context auto-compaction loop.

---

### 1. Universal 3-in-1 Cross-Platform USB Portable Suite
* **Single Universal Download (`Orbital-X-Portable.zip`):** One single archive that works seamlessly across all three desktop operating systems without separate downloads.
* **1-Click Native Launchers for Every OS:**
  * **Windows:** `Orbital X.exe` & `launch-portable.bat`
  * **macOS:** `Orbital X.app` & `launch-mac.command`
  * **Linux:** `Orbital-X.AppImage` & `launch-linux.sh`
* **Unified Portable Data Store (`./Data/`):** A shared portable directory contains `.orbital/settings.json`, custom skills, agent prompt presets, extensions, and persistent chat sessions. When moving your USB drive between your personal Windows machine, work MacBook, or Linux workstation, all your memory rules, preferences, and conversations travel with you with zero installation.

---

### 2. VS Code & Antigravity Integrated Terminal Redesign
* **Command Decoration Gutter Markers:**
  * Finished / executed commands display a crisp blue circle glyph (`●`) in the left gutter.
  * Active prompt lines display a hollow gray circle glyph (`○`) in the left gutter.
* **Real-Time Interactive Command Syntax Highlighting:**
  * Commands (`cd`, `git`, `npm`, `cargo`, `node`, `python`, `code`, etc.) are highlighted in gold/yellow (`#dcdcaa`).
  * Flags and parameters (`-v`, `--help`, `-m`) are highlighted in purple (`#c586c0`).
  * Strings and paths (`'.\Orbital X'`, `"file.txt"`, `src/main.rs`) are highlighted in cyan (`#4ec9b0`).
  * Subcommands and verbs (`commit`, `push`, `pull`, `build`, `test`) in light blue (`#9cdcfe`).
  * Real-time syntax coloring mirror updates as you type with a blinking block cursor (`█`).
* **Header Toolbar & Active Shell Indicator:**
  * Redesigned top tab bar: `Problems`, `Output`, `Terminal` in clean title case with active pill background.
  * Right-side active shell pill: `>_ powershell - <Workspace> ⚠️` indicating the active shell profile and instance status.
  * Profile selector (`+ ⌄`), split terminal (`[|]`), trash kill (`🗑️`), more actions (`···`), maximize/restore panel (`⛶`), and close (`✕`).
* **Clickable Terminal File Links:** Regex detection turns paths like `src/main.rs:42:10` into 1-click links that immediately jump to that file and column in Monaco Editor.

---

### 3. AI Chat Context Auto-Compaction Resolution
* **Active Token Measurement:** Filtered compaction token counters to active messages only, preventing stale compacted turns from triggering repeat loops.
* **Elevated 90% Threshold & 12-Turn Minimum:** Context compaction only activates when reaching 90% capacity with at least 12 active dialogue turns.
* **Single-Turn Latch Guard:** Guarantees compaction runs at most once per user turn, preventing the agent from being trapped in an auto-compaction loop without executing tools.
* **Tool Integrity Protection:** Rewinds message slicing to ensure assistant tool calls are never detached from tool results, preventing orphaned tool-role errors in local Ollama models.
