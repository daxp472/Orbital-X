## 1. Executive Summary & Objective

Iteration 007 delivers high-integrity autonomous execution, mathematical reasoning calibration, kernel-level confinement modes, unified contextual ergonomics, and complete runtime hardening:

1. **Reasoning, Evidence & Calibration Engine:**
   - Grounded in mathematical calibration:
     $$\psi = \min(\omega_{logic}, \omega_{evidence})$$
   - Formulates logical consistency scores ($\omega_{logic}$) and empirical evidence grounding ($\omega_{evidence}$).
   - Generates calibrated evidence badges on assistant turn completions and enforces pre-tool execution safety guards.
   - Fixed all ledger scoping issues across execution loops with a dynamic module proxy.

2. **Ask vs Chat Confinement Modes:**
   - **💬 Ask Mode:** Strict conversational read-only mode. Blocks all disk mutations, file creations, patches, deletes, and executions at the Rust policy engine level (`AgentMode::Ask`).
   - **⚡ Chat / Agent Mode:** Full IDE execution mode allowing autonomous code writing, editing, and tool calling.
   - Added interactive segmented pill control `[ 💬 Ask ] [ ⚡ Chat ]` in the composer toolbar.

3. **Autonomous Direct File Writing:**
   - Multi-layer heuristics in the agent loop detect when code blocks belong to target files.
   - When code is generated, the agent calls `write_file` / `save_file` directly to disk instead of trapping code inside chat text blocks.

4. **Inline AI Code Autocompletion (Ghost Text):**
   - Monaco editor ghost text suggestions powered by local Ollama models with a 180ms debounce.
   - Fast syntactic fallback heuristics provide instant completions even when offline.

5. **Unified Context Menu Architecture:**
   - Purged all legacy overlapping menus and unified context menus across File Tree, Tabs, Editor, Terminal, and Chat.
   - Pixel-perfect icon alignment and keyboard shortcuts (<kbd>Ctrl+X</kbd>, <kbd>Ctrl+C</kbd>, <kbd>Ctrl+V</kbd>, <kbd>Shift+Alt+C</kbd>, <kbd>Shift+Alt+P</kbd>, <kbd>F2</kbd>, <kbd>Del</kbd>, <kbd>@</kbd>).

6. **Full AST Scope Audit & Zero Undeclared Variables:**
   - Conducted an automated AST traversal using ESTree/Rollup across every JavaScript file in `src/js/`.
   - Resolved all reference errors at the root cause:
     - `evidenceLedger` proxy and loop scope in `agent.js`.
     - `isFileWriteRequest` variable scoping in `agent.js`.
     - `pollTelemetry` and `showToast` imports in `settings.js`.
     - `showToast` import in `wizard.js`.
     - Block scoping in `extensions.js`.

7. **Native Drag & Drop Hardening:**
   - Prevented drag-and-drop race conditions using persistent drag payload buffers.
   - Added support for dragging external files from Windows Explorer directly into Orbital X.

8. **Settings & Developer Suite:**
   - Added live system RAM usage tracking in the status bar and settings developer pane.
   - Persisted terminal appearance configuration (`fontFamily`, `fontSize`, `lineHeight`, `scrollback`, `cursorStyle`, `cursorBlink`) across restarts.
   - Theme consistency aligned across `theme-dark`, `theme-light`, `theme-hc`, and `midnight-blue`.
