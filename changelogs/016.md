# Orbital X v2.4.2 — Release Highlights

## What's New in Version 2.4.2

Orbital X v2.4.2 delivers major advancements across multi-turn conversational memory grounding, 60-second guided onboarding with one-click local model pulls, crash-safe buffer & draft session recovery, zero-freeze large repository guardrails, and dedicated multi-slot agent terminals with critical command approval shielding.

---

### 1. Multi-Turn Conversational Memory & Copilot Grounding
- **Preceding Turn Context Memory**: The agent now anchors every follow-up instruction to its preceding target files, user intents, and tool outcomes. Saying *"now add a sum function to it"* or *"test that in Python"* carries continuous context without re-asking *"which file?"*.
- **Token-Efficient Prompt Construction**: Eliminated duplicated context block concatenation in the system prompt, saving hundreds of context tokens per turn on local LLMs.
- **Scientific Verification ($\psi$) Session Persistence**: Mathematical calibration badges ($\psi = \min(\omega_{\text{logic}}, \omega_{\text{evidence}})$) are saved into conversation history and restored across older chats and app reloads.

---

### 2. First-Launch Onboarding Tour (The First 60 Seconds)
- **Visual Button Placement Tour**: A 5-step guided walkthrough highlighting where the 4 primary controls are placed: AI Chat Composer (`Ctrl+L`), Project Memory & Rules (`Ctrl+Shift+M`), Integrated Terminals (`Ctrl+\``), and Review Changes.
- **Auto-Detect & 1-Click Pull `qwen2.5-coder:7b`**: Automatically probes local Ollama status; if no code model is present, provides a single-click button to download and configure `qwen2.5-coder:7b` with live feedback.
- **Interactive Sample Project**: Launch an instant test drive workspace with unit tests and pre-filled prompt to immediately test Agent Pro and Monaco Diff within the first minute.

---

### 3. Crash-Safe Session & Draft Recovery
- **3-Second Background Auto-Persist**: Dirty Monaco editor buffers, unsaved scratch code, and exact cursor positions are automatically backed up to `.orbital/drafts/` every 3 seconds via native Rust.
- **Instant Power-Loss Recovery**: When reopening Orbital X after a sudden power loss or crash, all unsaved files, dirty indicators, and cursor positions are restored safely.

---

### 4. Zero-Freeze Large Repository Guardrails
- **Fast .gitignore & Common Giant Folder Filters**: Native AST indexer prunes `node_modules/`, `target/`, `dist/`, `build/`, `.git/`, `.orbital/`, `.next/`, `vendor/`, and custom `.gitignore` patterns.
- **500 KB File Size Ceiling**: Files over 500 KB are bypassed during AST semantic parsing, guaranteeing repositories with 100,000+ files open in under 300 ms with zero CPU freeze.

---

### 5. Dedicated Multi-Slot Agent Terminals & Critical Command Gate
- **Live Agent Terminals 1, 2 & 3**: When an agent runs build, test, or git commands, the terminal panel automatically opens and focuses the active agent terminal so you see the command output in real time.
- **Purpose Tags & 1-Click Process Termination**: Tabs display active purpose tags (`Build`, `Test Suite`, `Git Action`) with an instant **[⏹ Kill]** button and `Ctrl+C` interrupt handling.
- **Suggest Command to User Terminal**: New tool `suggest_user_terminal_command` enables the agent to safely queue commands in your interactive terminal for review.
- **Critical Command Security Gate**: High-risk operations (`git push`, `git reset --hard`, `git clean -f`, `rm -rf`) require explicit user confirmation before execution.
