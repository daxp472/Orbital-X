# Orbital X v2.4.7 — Release Highlights

## What's New in Version 2.4.7

Orbital X v2.4.7 delivers the **Adaptive Persona Engine & Isolated Calibration Studio**, a redesigned **Apple HIG Inset Grouped Settings Page**, a **Compact Composer Popover**, **WCAG AA Contrast Parity**, **FocusTrap Keyboard Accessibility**, and unified design tokens across both Light and Dark themes.

---

### 1. Adaptive Persona Engine & Apple HIG Studio
* **4 Inbuilt Locked Architectural Archetypes:**
  - **Atlas (Strategic Co-Pilot):** Strict opening with a 1-sentence executive summary, calm anticipatory chief-of-staff execution, and proactive downstream edge-case flags.
  - **Pulse (Minimalist Precision):** Zero conversational fluff. Delivers strictly code blocks, unified diffs, and surgical root causes.
  - **Nova (Pair-Programmer & Mentor):** Warm, supportive, and explanatory; grounds concepts in clear everyday analogies and architectural mental models.
  - **Vanguard (Kernel & Security Auditor):** Strict zero-trust auditor; evaluates memory safety, race conditions, invariant integrity, and security vulnerabilities first.
* **Auto Mode (Adaptive Intelligence):** Global persistent profile (`~/.orbital/auto_persona.json`) compiling prompt cadence, diff approvals, and 👍 / 👎 reactions into a live Behavioral Constitution.
* **Apple Inset Grouped Settings Design:** Clean macOS System Settings layout (`.persona-selection-group`) with full-row clickability, custom archetype avatars, 1-line descriptions, and radio checks.
* **Adaptive Intelligence Studio Toolbar:** Dedicated telemetry cards, a live **Surveys Enabled** toggle switch, reinforced vs. avoided traits chips, and an active constitution viewer with a 1-click **Copy** button.

---

### 2. Compact Composer Popover & Checkmark Isolation
* **Refined Dimensions:** Sized down to a sleek **220px** width with single-line descriptions and ellipsis truncation.
* **Universal High-DPI Emojis:** ✨ Auto, 🛡️ Atlas, ⚡ Pulse, 🤝 Nova, and 🔬 Vanguard.
* **Checkmark Isolation:** Resolved multi-check display so checkmarks appear strictly on the currently active personality.

---

### 3. IPC Parameter Serialization Hardening
* Fixed duplicate parameter deserialization collision in `persona_set_active`, ensuring seamless, error-free personality switching in native desktop builds.
* Cleaned up `persona_record_feedback`, `persona_submit_survey`, and `persona_synthesize_deep_profile` parameter mapping.

---

### 4. Accessibility & Design Token System (WCAG AA)
* **Contrast Compliance:** `--text-secondary` in Light theme updated to `#424245` and Dark theme to `#a0a0a5`, achieving strict 4.5:1 WCAG AA contrast ratio.
* **Apple HIG Focus Ring:** Global `.focus-ring` utility with `:focus-visible` across all interactive inputs, cards, and buttons.
* **Modal Focus Trap:** Comprehensive focus-trapping and `Escape` key listeners ensuring zero background bleed while dialogs are open.
* **Unified Design Tokens:** Standardized border radii, elevation box-shadows, and 7px pill scrollbars across all surfaces.
