# Orbital X v2.4.1 — Release Highlights

## What's New in Version 2.4.1

Orbital X v2.4.1 introduces major foundational upgrades: a complete Knowledge & Durable Memory management subsystem, in-editor and chat-turn file review decks with full Accept/Reject controls, dedicated multi-slot AI terminals with execution security shielding, scoped working directory control, and total eradication of ghost/hallucinated file variants.

---

### 1. Interactive File Review & Accept/Reject Controls
- **Per-File & Batch Decision Decks**: Every agent turn now renders a structured file modification deck containing `[✓ Accept]` and `[✕ Reject]` action buttons per file, alongside batch `[✓ Accept All]` and `[✕ Reject All]` triggers.
- **Top Panel Header Actions**: Integrated `#btn-header-accept-all` and `#btn-header-reject-all` inside the `.review-changes-bar` above the chat timeline for immediate bulk decisions.
- **Instant Rollback Engine**: Rejection reverts both the live Monaco editor buffer and the underlying disk file to its exact pre-tool snapshot.
- **Human Edit Confinement**: Manually created or edited files in the project explorer or editor tabs are strictly isolated from the AI review queue.

---

### 2. Knowledge & Core Memory Management Page
- **Full-Screen Knowledge Hub**: Dedicated modal (`#modal-memory-manager`) featuring tabs for Core Memory, Information Directory, and Architectural Semantic Graph.
- **Apple HIG Memory Drawer**: Replaces browser prompts with a rich editing drawer supporting 1–5 star importance weighting, category classification (Architecture, Conventions, Rules, Decisions), and persistent workspace storage.
- **Information Directory Scanner**: Analyzes project build manifests (`package.json`, `Cargo.toml`, `requirements.txt`), primary entrypoints, and active codebase dependencies.

---

### 3. Dedicated AI Terminal Fleet & Execution Security Shield
- **Autonomous Multi-Slot Terminals**: Supports up to 3 dedicated AI terminals (`🤖 Agent 1`, `🤖 Agent 2`, `🤖 Agent 3`) showing running command status and active output.
- **Instant Process Termination**: Prominent **[⏹ Kill Process]** button on running agent terminals to immediately abort stalled jobs or runaway commands.
- **Critical Command Security Shield**: Destructive or high-risk operations (e.g. `git push`, `git reset --hard`, `sudo`) are blocked from silent execution and can be routed to the user's terminal with 1-click confirmation.

---

### 4. Scoped Working Directory Control
- **Target Folder Isolation**: Tools `set_working_directory` and `get_working_directory` enable the agent to autonomously restrict its commands and file queries to sub-folders (e.g. `frontend/`, `server/`).
- **Policy Enforcement**: Rust-backed policy verification across all operating modes (Agent Pro, Dev, Ask).

---

### 5. Elimination of Ghost File Hallucinations
- **Truncated Extension Rejection**: Rust backend and frontend interceptors discard single-letter truncated extensions (such as `hello.j` generated alongside `hello.js`).
- **Idempotent Write Guard**: Skips secondary safety code-block parsing if tools have already completed file writes.

---

### 6. Clean Welcome Hero & Responsive Chat Polish
- **Welcome Hero Restoration**: New chats created via `+` (or welcome buttons) cleanly display the 4-card action starter dashboard without system greeting bubbles.
- **Sticky Actions**: Message action bars remain permanently visible without hovering flicker.
