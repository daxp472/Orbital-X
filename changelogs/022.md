# Orbital X v2.4.8 — Core Agent Speed, Universal GitHub Skills & Daily-Driver Polish

## Core Agent Speed & Response Quality (30+ tok/s Target)
- **Ollama Throughput Tuning (`src-tauri/src/providers.rs`):** Added `num_batch: 512` for rapid prompt evaluation, dynamic `num_ctx: 8192` default to prevent KV cache spillover into slow CPU RAM, and `available_parallelism()` thread tuning while keeping `keep_alive: "30m"` hot in VRAM.
- **Structured 4-Stage Prompt Pipeline (`src/js/components/agent.js`):** Streamlined system prompt assembly into `[SYSTEM & PERSONA] -> [ACTIVE SKILL] -> [FOCUSED AST & MEMORY SLICE] -> [USER TASK]`, eliminating ~400 tokens of per-turn prompt bloat for faster local model inference (`Qwen`, `Llama 3`, `DeepSeek`).

## Universal GitHub Skills, Chat Commands & Apple HIG Skill Reader
- **Universal GitHub Repository Discovery (`src-tauri/src/skills.rs`):** Scans the full recursive Git tree to locate `SKILL.md` across any convention (`SKILL.md`, `skills/*/SKILL.md`, `.agents/skills/*/SKILL.md`, `.claude/skills/*/SKILL.md`, `plugins/*/SKILL.md`), falls back to `AGENTS.md` / `CLAUDE.md` / `GEMINI.md`, synthesizes clean YAML frontmatter when missing, and downloads companion `references/`, `resources/`, `agents/`, and `scripts/` files.
- **Direct Chat Skill Commands (`src/js/components/agent.js`):** Added `/skill <name> [task]`, `/install-skill <url-or-repo>`, direct `npx skills add <owner/repo> --skill <name>` parsing, and `@skill:<id>` autocomplete.
- **Apple HIG Read-Only Skill Reader (`src/js/editor/monaco.js`, `src/styles/layout.css`):** Strips raw YAML frontmatter, renders structured metadata pills (`Author`, `Version`, `Priority`, `Triggers`, `Globs`, `Allowed Tools`, `Tags`), checklist styling, and sticky actions (`▶ Run Skill in Chat`, `✓ Enabled`, `↻ Update from GitHub`, `Uninstall`, `Raw Source`).

## Daily-Driver Reliability & Native Polish
- **Zero-Duplicate OS File/Folder Dialogs (`src-tauri/src/lib.rs`, `src/js/services/tauri.js`, `src/js/app.js`):** Added Rust `DIALOG_IN_FLIGHT` `AtomicBool` RAII guard and JS `dialogInFlight` mutex so cancelling `open_folder_dialog` or `pick_save_file` never spawns stacked OS dialogs.
- **Zero-Freeze Native Modals (`src/js/services/dialogs.js`):** Added `showAlertDialog` and replaced all 28+ blocking browser `alert()` / `confirm()` / `prompt()` calls across the IDE.
- **Event-Driven PTY Streaming & External File Watcher (`src-tauri/src/terminal.rs`, `src-tauri/src/lib.rs`, `src/js/components/terminal.js`):** Replaced `setInterval` terminal polling with instant Tauri `pty-data` push events and added a background `workspace-files-changed` watcher that auto-refreshes File Explorer and clean open tabs.
- **1-Click Portable Memory Backup & CSS Token Sync (`src/js/components/memory.js`, `src/styles/themes.css`, `src/js/editor/monaco.js`):** Added 1-click Portable backup in the Memory Manager modal and dynamic Monaco theme synchronization from CSS tokens.
