# Orbital X v2.4.5 — Release Highlights

## What's New in Version 2.4.5

Orbital X v2.4.5 delivers **Responsive Split-Screen Window Architecture** (Half-Screen and Quarter-Screen focus modes with top view-switcher), **Read-Only Markdown Skill Viewer Tab** in Monaco with glassmorphic action controls, **Community Skills Hub & Importer** (curated packs with 1-click install, raw GitHub URL import, and local folder import), **Modular Agent Working Skills** (`agent.md` and `SKILL.md` system), and **Strict Per-Workspace State Isolation**.

---

### 1. Half-Screen & Quarter-Screen Responsive Window Architecture
* **Unrestricted Window Resizing:** Configured `minWidth: 420` and `minHeight: 360` so Windows Snap (`Win + Arrow Keys`), macOS Stage Manager/Split View, and Linux tiling managers resize Orbital X cleanly without clipping.
* **Half-Screen Adaptive Mode (< 960px):** Automatically collapses the left sidebar into a slide-over drawer, dedicating primary horizontal space to Monaco Editor and AI Chat while keeping status bar pills compact.
* **Quarter-Screen Focus Mode (< 640px):** Switches the workspace into a single-pane focus layout with a top pill switcher (`[ Explorer | Editor | AI Chat ]`) for one-click pane switching in narrow snap quadrants.
* **Zero-Flicker Monaco Resizing:** Smooth `editor.layout()` calls on all breakpoint transitions with zero horizontal overflow.

---

### 2. Read-Only Markdown Skill Viewer Tab
* **Dedicated Monaco Document Tab:** Replaced the cramped modal preview with a full-width read-only Markdown document tab (`skills://<slug>`).
* **Glassmorphic Sticky Action Bar:** Quick-action controls directly in the editor header:
  - `[✓ Install]` / `[✓ Update]`
  - `[Enable / Disable]` toggle
  - `[Uninstall]`
  - `[Open Raw Source]` to inspect or edit the underlying `SKILL.md` file.
* **Full Light & Dark Theme Parity:** Rendered with syntax-highlighted code blocks, metadata chips, and responsive padding across all themes.

---

### 3. Community Skills Hub & Safe Importers
* **Curated Offline Registry:** 9 built-in production skill packs (Rust Systems, React/Next.js, Python/FastAPI, Apple HIG UI/UX, Security Audit, Automation, TDD & Debugging).
* **Safe External URL Importer:** Install any custom skill from raw GitHub URLs or community markdown files with path traversal security (`validate_skill_slug`).
* **Local Folder Importer:** Direct 1-click import of local skill directories into the persistent `~/.orbital/skills/` repository.
* **Categorized Tag Filters:** Filter by `Rust`, `React`, `Python`, `Security`, and `Testing` with live badge counts.

---

### 4. Modular Agent Working Skills System (`agent.md` & `SKILL.md`)
* **Workspace & Global Discovery:** Scans `<workspace>/agent.md`, `<workspace>/.orbital/skills/*/SKILL.md`, and global `~/.orbital/skills/*/SKILL.md`.
* **Lightweight Skill Index Digest (<250 Tokens):** Compact summary index injected into the system prompt; local models load full instructions on demand via `read_skill`.

---

### 5. Strict Per-Workspace State Isolation
* **Zero Cross-Workspace State Bleed:** Memory, semantic index caches, chat sessions, and terminal state are isolated per workspace path. Switching workspaces cleanly flushes and reloads the active workspace environment.
