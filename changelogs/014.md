# Orbital X v2.4.0 — Release Highlights

## What's New in Version 2.4.0

Orbital X v2.4.0 delivers major advancements across high-speed inline code suggestions, multimodal vision guidance, clean agent conversation ergonomics, and an Apple HIG-grounded chat composer redesign.

---

### 1. High-Speed Contextual Antithesis Inline Completions
- **Zero-Latency Semantic Inversion Engine**: When typing inside an `else`, `elif`, or fallback branch, Orbital X inspects the preceding `if` block, inverts the semantic meaning (e.g., `can` $\rightarrow$ `cannot`, `valid` $\rightarrow$ `invalid`, `success` $\rightarrow$ `failed`, `allowed` $\rightarrow$ `not allowed`), and instantly completes the full statement (`("you cannot drive a car");`).
- **First-Frame Execution (0ms)**: Returns immediately without waiting for model network latency or debounces.
- **Universal Multi-Language Support**: Operates across JavaScript, TypeScript, Python, Rust, Go, Java, C++, C, C#, PHP, Swift, and Dart.
- **Condition Header Deduplication**: Prevents repeating conditions or brackets when the developer types control headers (`if(...) {`).
- **Decoupled Inference**: Lightweight inline coder models (1.5B/3B) remain decoupled from heavy chat models, backed by 30-minute VRAM persistence in Ollama.

---

### 2. Multimodal Vision Guidance & Model Switcher
- **Screenshot-to-Agent Support**: Attach, paste (Ctrl+V), or drag UI screenshots and error traces directly into the chat composer.
- **Vision Model Warning Modal**: Intelligently warns when the active model is text-only (e.g., Qwen text models) and offers a 1-click switch to recommended multimodal models (`llama3.2-vision`, `llava`, `moondream`, `gpt-4o`, `claude-3-5-sonnet`).

---

### 3. Apple HIG Composer Redesign & Realignment
- **Left-Aligned Attachments**: Context Clip, Screenshot Upload, and `@` File Mention buttons are positioned together on the bottom-left.
- **Right-Aligned Telemetry & Send**: Live token counter (`~0 tokens`), context ring (`0%`), and Send action are neatly docked on the bottom-right.
- **Responsive Dual-Row Architecture**: Mode toggle (Ask/Chat) and Model selector pills sit in the dedicated top bar, maintaining perfect legibility even when resizing the chat panel narrow.
- **Apple HIG Attachment Popover**: Categorized attachment selector (`Active Context`, `Project & Architecture`, `Dev & Diagnostics`) with vector icons.

---

### 4. Cohesive Single-Container Agent Responses
- **Anti-Fragmentation Architecture**: Complex multi-step tasks no longer flood the timeline with 10–15 separate response boxes.
- **Interactive Activity Tray**: Intermediate tool runs stream neatly inside a collapsible activity disclosure widget.
- **Single Rating Bar**: Exactly one like/dislike rating bar per agent turn.
- **Sticky Feedback Bar**: Zero-layout-shift docked action bar on completed assistant cards.

---

### 5. Clean Session Lifecycle & Welcome Hero
- **Zero-Message New Chats**: Clicking the `+` button opens a clean Orbital X AI Assistant Welcome Hero with 4 quick action starter cards instead of noisy system greetings.
- **Non-Destructive Context Compaction**: Compacting context window memory preserves the full visual message history with an inline divider.

---

### 6. Review Changes Isolation
- **AI-Only Mutation Tracking**: The "Review Changes" button and diff modal strictly isolate modifications authored by the AI agent (`write_file`, `patch_file`, `delete_file`), filtering out human edits made in the explorer.

---

### 7. Structured 4-Stage Error Architecture
Standardized diagnostic error presentation (OX-100 through OX-500) classified across:
- **Stage 1**: Local Ollama / Daemon Runtime
- **Stage 2**: AI Model & Provider
- **Stage 3**: Orbital X Core Engine Fault
- **Stage 4**: Workspace & User Operations
