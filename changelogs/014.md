# Orbital X v2.4.0 — Release Highlights

## What's New in Version 2.4.0

Orbital X v2.4.0 introduces major enhancements to agent conversational ergonomics, persistent editor inline completions, transactional workspace review isolation, and an Apple HIG-grounded chat composer overhaul.

---

### 1. Persistent Inline Suggestions (Ghost Text Retention)
- **Eliminated 1-Second Disappearance**: Resolved auto-save synchronization collisions that previously wiped Monaco's model state and cleared ghost text after a 1000ms delay.
- **Prefix-Matching Ghost Retention**: As you continue typing characters matching the suggestion prefix, the suggestion dynamically stays on screen and adjusts in place without re-querying the model.
- **Divergence Invalidation**: The ghost text only updates or re-fetches when you type diverging code.

---

### 2. Singular Cohesive Agent Turns (Anti-Fragmentation)
- **Single Response Container**: Multi-step agent actions (such as editing files, inspecting workspaces, or running diagnostics) no longer fragment into 10–15 disconnected message cards.
- **Interactive Activity Tray**: Intermediate tool executions and command outputs are cleanly grouped inside an expandable collapsible activity tray within the assistant's turn.
- **Unified Rating Bar**: One single like/dislike rating bar at the bottom of the completed response card, eliminating rating clutter across multiple intermediate bubbles.

---

### 3. Review Changes Isolation (AI vs. Human Edits)
- **Isolated AI Staging**: The "Review Changes" button and diff modal now strictly track and surface AI-authored file modifications (`write_file`, `patch_file`, `delete_file`).
- **Human Explorer Edits Ignored**: Manual edits in the editor, file moves, renames, and git modifications by the developer are excluded from AI review staging.

---

### 4. Non-Destructive Context Compaction
- **Complete Visual Timeline Preservation**: Compacting or resetting the context window no longer deletes existing chat messages from the timeline.
- **Inline Compact Divider**: Inserts a subtle, high-clarity indicator showing where older turns were summarized, keeping the visual chat history intact while freeing context window memory for model inference.

---

### 5. Sticky, Shift-Free Message Feedback Bar
- **Zero Layout Shift**: Action and rating buttons no longer toggle card height on mouse enter/exit.
- **Permanently Docked**: Docked smoothly at the bottom-right of assistant message cards with subtle resting opacity and seamless hover vibrancy.

---

### 6. Composer Option A & Apple HIG Attachment Popover
- **Option A Composer Architecture**: Streamlined input box with subtle glassmorphism, responsive auto-resizing, live token budget indicator, compact segmented Ask/Chat pill, compact model selector, and speculative toggle.
- **Redesigned Attachment Menu**: Replaced raw flat menus with a categorized Apple HIG popover card (`Active Context`, `Project & Architecture`, `Dev & Diagnostics`), complete with vector SVG icons and clear subtitles.
