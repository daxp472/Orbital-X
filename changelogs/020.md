# Orbital X v2.4.6 — Release Highlights

## What's New in Version 2.4.6

Orbital X v2.4.6 delivers the **Adaptive Persona Engine & Isolated Calibration Studio**, an **Apple Human Interface Guidelines (HIG) AI Personalities Studio**, a **Compact Personality Selector Popover**, **Zero-Bleed IPC Stabilization**, and comprehensive cross-platform distribution updates.

---

### 1. Adaptive Persona Engine (`PersonaEngine` Rust Runtime)
* **4 Inbuilt Locked Archetypes:**
  - **Atlas (Strategic Co-Pilot):** Strict opening with a 1-sentence executive summary, calm anticipatory chief-of-staff execution, and proactive downstream edge-case flags.
  - **Pulse (Minimalist Precision):** Zero conversational fluff. Delivers strictly code blocks, unified diffs, and 1–2 sentence root causes.
  - **Nova (Pair-Programmer & Mentor):** Warm, supportive, and explanatory; grounds concepts in clear everyday analogies and architectural mental models.
  - **Vanguard (Kernel & Security Auditor):** Zero-trust auditor; performs security, data race, invariant, and memory safety assessment first.
* **Auto Mode (Adaptive Intelligence):** Global persistent profile (`~/.orbital/auto_persona.json`) compiling prompt cadence, diff approvals, and 👍 / 👎 reactions into a live Behavioral Constitution.

---

### 2. Apple HIG AI Personalities Studio (Settings UI)
* **Featured Auto Mode Hero Card:** Glassmorphic layout with active cyan glow, status indicators (Calibration Streak, Total Calibrations, Adaptive Turns), and 1-click activation.
* **Specialized Archetypes Inset Group:** Clean, responsive inset cards with rounded icon avatars, concise 1-line descriptions, and Apple circular selection indicators. Entire cards are directly clickable.
* **Learned Behavior & Alignment Studio:** Inset grouped box tracking reinforced traits (cyan) and avoided constraints (red) with 1-click **Launch Calibration Studio** and **Reset Auto Profile** actions.
* **Live Behavioral Constitution Viewer:** Full-width monospace viewer displaying the exact system prompt injected into local models.

---

### 3. Compact Personality Popover & Checkmark Fix
* **Refined Dimensions:** Sized down to a sleek 236px width with single-line descriptions and ellipsis truncation.
* **Checkmark Parity:** Fixed multi-check display so checkmarks appear strictly on the currently active personality.
* **Visual Polish:** Upgraded Nova icon to a crisp, high-DPI lightbulb symbol (`💡`) matching macOS and Windows design palettes.

---

### 4. IPC Serialization & Argument Boundary Hardening
* **Dual-Format Parameter Ingestion:** Hardened Rust commands to accept both camelCase (`personaId`) and snake_case (`persona_id`), ensuring zero argument mismatch errors across all Tauri IPC layers.
