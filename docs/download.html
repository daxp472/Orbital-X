Zero-Installation Hybrid Architecture

Orbital X Portable — Carry Your IDE on Any USB Drive.

Plug your USB drive into any computer and immediately begin coding with your personalized environment. No administrator privileges, no installer wizards, and zero residual files left on the host system drive.

What Travels on Your USB Drive
  • IDE preferences & editor appearance
  • Installed extensions & community skills
  • Agent instructions & prompt presets
  • Portable chat history & session states
  • Optional project memory backups
What the Host Computer Supplies
  • Local Ollama runtime & downloaded models
  • GPU hardware acceleration & system RAM
  • Native compilers (Cargo, Node, Python, C++)
  • Primary project workspaces & source code
  • Isolated .orbital/ project memory store
Dual-Safe Project Isolation: Project memory resides inside each project's local folder. If your USB drive is ever unplugged or misplaced, your project code and workspace memories remain 100% safe on the host computer.

Download & Installation FAQ

Do I need administrator privileges to install or run Orbital X?
+

No. Both the Windows NSIS user installer and the Portable USB edition install and execute entirely within user-level directories without requiring Windows UAC administrator elevation.

How does the Portable edition keep my settings on the USB drive?
+

When Orbital X starts, it inspects its directory for a Data/ folder or PORTABLE marker. When detected, it re-routes the internal user data directories, extensions, preferences, and session files to the USB drive, keeping the host drive untouched.

Can I use cloud AI models like Claude, GPT-4, or Gemini?
+

Yes. While Orbital X is built offline-first with local Ollama as the default, you can configure OpenAI, Anthropic, Google Gemini, OpenRouter, and Groq API keys in Settings at any time.
