Recommended Models & Hardware Advisor

Pair Orbital X with the right local AI model for your hardware. Zero token bills, zero cloud lock-in, zero latency lag.

⚠️

Critical Hardware Baseline: 16 GB Minimum System RAM Required

System RAM ≥ 16 GB

Local coding models execute directly on your PC hardware. For smooth editor performance, multi-file code indexing, and IDE multitasking, a minimum of 16 GB of System RAM is required (32 GB recommended for autonomous Agent Pro).

Full GPU VRAM (Ideal)

When the quantized model weights fit entirely inside your GPU VRAM (e.g. RTX 3060/4070 or Apple Silicon Unified Memory), you get full GPU compute reaching 60 to 120+ tokens/sec with zero editor stutter.

CPU & RAM Offload (Hybrid)

If a model exceeds GPU VRAM, Ollama offloads leftover layers to System RAM and computes them on the CPU. It remains functional at 15–30 tok/s, but heavily taxes system memory.

Out-of-Memory Freeze Guard

Attempting to run a 14B or 32B model on a computer with only 8 GB RAM will cause severe disk paging and OS lockups. Always match model size to your hardware using the selector below.
