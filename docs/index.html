// Orbital X — Kernel Policy Engine
pub struct PolicyDecision {
pub allows: bool,
pub requires_approval: bool,
pub risk: RiskLevel,
}

// Evaluates tool invocation strictly inside Rust boundary
pub fn evaluate_tool_policy(tool: &str, mode: &str) -> PolicyDecision {
match (tool, mode) {
("write_file", "dev") => PolicyDecision::require_diff_approval(),
("write_file", "agent_pro") => PolicyDecision::allow(),
_ => PolicyDecision::enforce_strict_approval(),
}
}

Built from First Principles

No bloated browser wrappers. No cloud middlemen. Pure native speed and complete developer autonomy.

⚡

Tauri 2 + Rust Core

Unlike Electron-based editors that bundle duplicate Chromium instances, Orbital X runs on an ultra-lean Rust backend with native Microsoft Edge WebView2. Idle RAM stays below 100 MB.

🦙

100% Local AI with Ollama

Plug directly into your local machine's Ollama instance (http://localhost:11434). Download and pull models directly inside the IDE with the built-in Ollama manager. Zero API keys, zero cloud costs.

🛡️

Tri-Mode Safety Policy

Switch effortlessly between Agent Pro (high autonomy), Dev Mode (approval cards with diff previews), and User Mode (strict per-action confirmation). Destructive commands are blocked at the Rust kernel.

💾

Durable Project Memory

Architectural decisions, build instructions, and team rules are automatically extracted and stored locally in .orbital/memory.json. Your AI remembers your project across restarts.

📝

Monaco Code Editor Upgraded

Battle-tested Monaco experience with active file path breadcrumbs, Go to Line (Ctrl+G), Go to Definition (F12), multi-cursor selection (Ctrl+Shift+L), zoom controls (Ctrl+=/-), and side-by-side diff review.

🖥️

Terminal History & Git Panel

Integrated terminal with 50-command persistent history navigation (↑/↓), built-in shell commands, and a complete Source Control panel with live diff review, staging, and one-click Git commits.

    ollama run qwen2.5-coder:7b
  2. Open Orbital X Settings:

    Press Ctrl + , or click the gear icon in the left activity rail.
