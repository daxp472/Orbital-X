# Orbital X v2.4.0 Implementation Plan — Composer Redesign, UX Refinements & Singular Turn Architecture

## Overview
This plan implements the Option A chat composer redesign, singular assistant response card architecture (ending message fragmentation), persistent inline ghost-text suggestions with prefix matching and auto-save protection, non-destructive context compaction, AI-isolated Review Changes tracking, zero-layout-shift rating buttons, upgraded clip context menu, and packaging for the v2.4.0 release.

---

## Proposed Changes & Tasks

### Task 1: Isolate Review Changes to AI Modifications Only
- **Files**: `src/js/services/changed-files.js`, `src/js/components/file-tree.js`
- **Goal**: Human file edits in the file tree or external git changes must NOT appear under the "Review Changes" button. Only AI-authored mutations (`write_file`, `patch_file`, `delete_file`) from `agent.js` are tracked in `canonicalFilesMap`.
- **Implementation**:
  - In `changed-files.js`, add an `isAiMutation: boolean` filter to `recordFileMutation`.
  - In `orbital:files-changed` event listener, verify `detail.source === 'ai'` or `detail.tool` is an agent tool before recording to `canonicalFilesMap`.
  - Remove the automatic ingestion of general git working tree files (`get_git_status`) into `canonicalFilesMap`. Git source control pane remains for human workspace tracking; Review Changes is dedicated to AI modifications.
  - Verify `updateChangedFilesUI()` accurately reflects AI-only changed file count.

---

### Task 2: Non-Destructive Context Compaction in Chat Timeline
- **Files**: `src/js/components/agent.js`
- **Goal**: When context window compaction occurs (auto or manual), earlier conversation history in the visual chat timeline must NOT be erased or removed from the DOM.
- **Implementation**:
  - In `compactAgentContext()`, prune `state.conversation` (or maintain a separate `state.contextPayload` for LLM prompt generation) while preserving the full message list in `state.fullHistory` or keeping the DOM timeline intact.
  - Remove `timeline.innerHTML = ''; renderFullTimeline(state.conversation);` which was wiping the DOM.
  - Instead, insert an inline context compaction divider `<div class="context-compacted-divider">` into the timeline showing `Context compacted — earlier turns summarized to free memory`.
  - Update `updateContextMeter()` to accurately reflect the reduced prompt token count.

---

### Task 3: Zero-Layout-Shift Like & Dislike Actions
- **Files**: `src/styles/polish.css`, `src/js/components/agent.js`
- **Goal**: Hovering over message cards must never shift card height or rearrange timeline layout.
- **Implementation**:
  - Update `.msg-action-bar` in `polish.css`:
    - Remove `display: none` / `display: flex` toggle on `:hover`.
    - Set `.msg-action-bar` to fixed position or stable reserved height (`opacity: 0; pointer-events: none; transition: opacity 0.15s ease;`).
    - On `.timeline-card:hover .msg-action-bar`, set `opacity: 1; pointer-events: auto;`.
    - Ensure `.msg-action-bar` is neatly anchored at the bottom-right corner of the card.
    - Provide a dedicated, stable squircle rating group for Like and Dislike buttons.

---

### Task 4 & 5: Singular Cohesive Assistant Response Container (Ending Turn Fragmentation)
- **Files**: `src/js/components/agent.js`
- **Goal**: A multi-step agent turn (e.g. editing a file with tool calls) must render as ONE singular response card with ONE set of rating buttons, rather than 4–5 fragmented bubbling cards.
- **Implementation**:
  - In `runAgentLoop()`, initiate **one** primary assistant turn card at the beginning of the turn.
  - For intermediate tool calls (reading, editing, running diagnostics), append compact, collapsible action rows (`<div class="agent-tool-activity-step">`) inside an expandable activity tray inside that same card.
  - Stream the final conversational response directly into the narrative section of that same card.
  - Attach the rating action bar (`attachMessageActions`) only ONCE to the bottom of the completed singular card.

---

### Task 6: Persistent Inline Suggestions with Prefix Matching & Auto-Save Guard
- **Files**: `src/js/editor/monaco.js`
- **Goal**: Ghost text must not disappear after 1 second, and must remain active while the user types characters matching the suggestion prefix.
- **Implementation**:
  - In `monaco.js`, intercept `orbital:file-written`: if the active editor's content matches the saved content (i.e. self-save from `saveTab`), do NOT call `ed.setValue()`. Calling `setValue()` resets the Monaco model, destroys ghost text, and resets cursor state.
  - In `registerInlineCompletions()`, cache the active suggestion text and its trigger position.
  - When the user continues typing: if the typed characters match the prefix of the pending ghost text, retain the suggestion with an updated range/offset instead of canceling and returning `{ items: [] }`.
  - Only call the backend completion model when the typed text diverges from the ghost text or when the user moves the cursor to a new location.

### Task 7: Option A Composer Redesign & Apple HIG Clip Menu Overhaul
- **Files**: `index.html`, `src/styles/polish.css`, `src/styles/components.css`, `src/js/components/agent.js`
- **Goal**: Redesign the chat composer layout to Option A, ensuring balance in both wide and narrow panel widths, and upgrade the clip attachment popup.
- **Implementation**:
  - **Option A Composer Box**:
    - Top area: Textarea with auto-expand and discreet token budget meter (`~0 tokens`).
    - Mode toggle (`Ask` / `Chat`): Redesigned as a subtle segmented switch neatly placed at top-right of the prompt box or integrated cleanly.
    - Bottom action bar:
      - Left group: Compact model badge (`Ollama: qwen3`) with integrated speculative pill indicator (`⚡ 3B Draft`).
      - Right group: Quick action buttons (`[Clip]`, `[Photo]`, `[@]`), circular context ring, and primary circular Send button.
    - Responsive flex rules: When the panel width is narrow (<320px), elements scale and wrap gracefully without horizontal overflow.
  - **Clip Attachment Menu Overhaul**:
    - Replace the raw context list in `openAttachmentMenu()` with an Apple HIG frosted card (`orbital-attachment-popover`).
    - Organize items into 3 clear visual categories:
      1. *Active Code*: Current File, Path Selector, Code Selection.
      2. *Workspace Context*: Architecture Graph, Project Dependencies, Folder Tree.
      3. *Environment & State*: Terminal Output, Git Working Diff, Diagnostics & Problems, Working Memories.
    - Style with 20px vibrancy backdrop-blur, category headers, SVG vector icons, and keyboard shortcuts.
