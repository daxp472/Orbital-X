What's New in Orbital X v2.3.8

Welcome to Orbital X v2.3.8. This release introduces a breakthrough Hybrid Portable Architecture, a redesigned Updates Suite with native release highlights, an upgraded Recent Conversations manager, and an audited Developer Diagnostic Suite.

Download v2.3.8 View on GitHub ↗
Core Architectural Milestone
Hybrid Portable Workstation on Any USB Drive
What's New: Carry your entire personalized IDE environment (theme, font, settings, extensions, community skills, agent instructions, and portable chats) on a USB drive under Data/.orbital/.
What Changed: Host computers provide raw power (Ollama models, GPUs, RAM, compilers). Project workspaces keep their own local .orbital/ memory, with 1-click dual sync to the USB drive.
How It Helps: Hop between home desktops, office workstations, and laptops seamlessly. Plug in your USB and your customized AI IDE is ready with zero setup.
Why It Matters: Never leaves traces on host storage. If the USB drive is unplugged, your project knowledge remains safe on your host computer.
Design & Release Intelligence
Redesigned Updates Suite & Native Markdown Viewer
What's New: Apple HIG-compliant Updates center with dynamic metrics tiles (Installed Version, Latest Stable, Release Channel, and Runtime Mode).
What Changed: Eliminated internal development report clutter. Users now enjoy polished release highlights rendered directly in safe native Markdown.
How It Helps: Completely eliminates the version mismatch bug. Installed versions are dynamically verified against the native desktop binary, stopping false update prompts.
Why It Matters: Clean, confident software upgrades with live download progress streaming and instant release note readability.
Conversation Productivity
Recent Chats Interface & Fast Session Filters
What's New: Integrated search bar and category tabs (Active, Pinned, Archived) with real-time conversation filtering.
What Changed: Replaced emoji controls with crisp SVG vector icons for Pinning, Archiving, Exporting, and Deleting chat sessions.
How It Helps: Quickly jump back to vital debugging sessions or prompt threads without scrolling through endless chat history.
Why It Matters: Keeps your workspace clean, focused, and organized across multi-day coding sprints.
Developer & Runtime Tools
Audited Developer Options & Security Simulator
What's New: Live Hybrid Portable Environment Inspector displaying USB mount roots, crash lock guard status, and synced project backups.
What Changed: Connected every control in Developer Options to real native Tauri APIs: live IPC round-trip latency benchmarks, Kernel security simulator, and state exporters.
How It Helps: Verify your backend performance with live sub-millisecond IPC benchmarks and test permission boundaries on arbitrary files.
Why It Matters: Zero non-functional or decorative placeholder controls. Every button provides actionable diagnostic power.
