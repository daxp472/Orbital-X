What's New in Orbital X v2.4.2

Welcome to Orbital X v2.4.2. This release introduces dedicated multi-slot agent terminals (Slots 1, 2, 3), crash-safe Monaco draft persistence, first-launch 60-second guided onboarding with sample testing suite, zero-freeze AST large repository guardrails, and conversational follow-up grounding.

Terminal Execution & Visibility
Dedicated Multi-Slot Agent Terminals (1, 2, 3)
What's New: Dedicated concurrent agent terminals (🤖 Agent 1, 🤖 Agent 2, 🤖 Agent 3) with dynamic purpose badges (Build, Test Suite, Git Action) and active process indicators.
What Changed: Bottom terminal drawer automatically opens and focuses the active agent slot during command execution. Added 1-click [⏹ Kill] button and security approval checks for critical Git commands (git push, git reset --hard).
How It Helps: Observe live terminal outputs and compilation logs in real time as the agent executes commands, with complete control to interrupt runaway commands at any moment.
Why It Matters: Full execution transparency and ironclad safety guardrails preventing unintentional repository disruptions.
Crash Resilience
Crash-Safe Session & Draft Recovery
What's New: Automatic background persistence of unsaved Monaco buffers, tab active states, dirty indicators, and cursor positions every 3 seconds to .orbital/drafts/session.json.
What Changed: On startup, the IDE detects any unclean shutdown or power cut and safely rehydrates dirty editor models with an unobtrusive recovery notification.
How It Helps: Never lose code edits, architectural notes, or draft functions during unexpected battery depletion or OS reboots.
Why It Matters: Mission-critical peace of mind for deep flow programming sessions without constant manual saving.
Onboarding & Getting Started
60-Second Guided Tour & Interactive Sample
What's New: Interactive 5-step guided walkthrough highlighting key IDE controls: Agent Chat (Ctrl+L), Memory & Knowledge (Ctrl+Shift+M), Terminals (Ctrl+`), and Monaco Diff Review.
What Changed: Auto-detects Ollama daemon status; provides 1-click ⚡ Pull Recommended Model (qwen2.5-coder:7b) and 1-click 🚀 Launch Interactive Sample Project.
How It Helps: Spins up a lightweight calculator.js and unit test suite in seconds, pre-populating an agent task so you can test features instantly.
Why It Matters: Enables new developers to experience private local AI code generation in under a minute without manual repo setup.
Architecture & Indexer
Zero-Freeze Large Repo AST Guardrails
What's New: Sub-300ms workspace opening on large-scale repositories with tens of thousands of source files.
What Changed: Rust indexer integrates .gitignore rules, hardcoded heavy exclusions (node_modules, target, dist, build), file size caps (<500 KB per AST file), and a 2,500 file indexing ceiling.
How It Helps: Eliminates IDE sluggishness, thread locks, and CPU freezing when opening massive enterprise or monorepo workspaces.
Why It Matters: Instantaneous semantic graph lookups while keeping system memory and CPU consumption feather-light.
Conversational AI Ergonomics
Conversational Continuity & Copilot Grounding
What's New: Conversational continuity block automatically grounds short follow-up prompts (e.g. "add the sum function to it" or "now write unit tests") to the prior turn's target files and tool execution state.
What Changed: Removed duplicate system prompt context concatenation, saving hundreds of context tokens per turn while sharpening local LLM instruction adherence.
How It Helps: Speak to the agent naturally as you would with GitHub Copilot or Antigravity, without tediously repeating filenames or parameters.
Why It Matters: Eliminates file targeting hallucinations and delivers predictable, coherent multi-turn code iterations.
Empirical Evidence Engine
Scientific Verification (Ψ) Session Persistence
What's New: Full persistence of scientific verification badges (Ψ) and model calibration confidence scores across conversation session switches and restarts.
What Changed: Chat timeline renderer binds recorded calibration scores directly to reloaded assistant turns with visual confidence level indicators.
How It Helps: Review empirical confidence levels for code suggestions created in earlier chat sessions at a glance.
Why It Matters: Maintains rigorous verification standards and traceability across long-running development workflows.
